# Как запустить TofsDevOps с нуля — простая инструкция

Эта инструкция для тех, кто нечасто работает с серверами. Ничего страшного здесь нет: вся настройка — это скопировать несколько команд и один раз вставить токен. Займёт 15–20 минут.

**Что получится в итоге:** у тебя в Telegram появится личный бот, который круглосуточно следит за твоими сайтами и пишет только тогда, когда что-то сломалось (и каждое утро — короткое «✅ всё в порядке»).

**Что понадобится:**
1. Аккаунт в Telegram (уже есть).
2. Сервер, который работает круглосуточно — подойдёт самый дешёвый VPS (см. Шаг 2).

---

## Шаг 1. Создать бота в Telegram (2 минуты)

1. Открой Telegram и найди в поиске **@BotFather** (официальный бот с синей галочкой).
2. Нажми **Start** (или напиши `/start`).
3. Отправь ему команду:
   ```
   /newbot
   ```
4. BotFather спросит имя — напиши любое, например `Мой DevOps`.
5. Потом спросит username — он должен заканчиваться на `bot`, например `moy_devops_bot`. Если занято — попробуй другой.
6. В ответ придёт сообщение с **токеном** — длинная строка вида `1234567890:AAEhBOweik6ad9r_QXMENQjcrGbqCr5yLYE`.

**Скопируй этот токен** — он понадобится на Шаге 4. Никому его не показывай: у кого токен — у того и бот.

---

## Шаг 2. Взять сервер (если ещё нет)

Боту нужен компьютер, который включён всегда. Обычно это VPS — виртуальный сервер в аренду, стоит от 3–5 $/мес (или 150–300 ₽/мес у российских провайдеров).

1. Зарегистрируйся у любого провайдера VPS (Timeweb, Selectel, Hetzner, DigitalOcean — кто удобнее).
2. При создании сервера выбери:
   - Операционная система: **Ubuntu 22.04** или новее.
   - Самый дешёвый тариф — боту хватит с запасом (1 CPU, 1 ГБ памяти).
3. После создания провайдер покажет **IP-адрес** сервера и **пароль** root-пользователя (или пришлёт на почту).

**Как зайти на сервер:**
- **Mac / Linux:** открой программу «Терминал» и введи (подставь свой IP):
  ```bash
  ssh root@123.45.67.89
  ```
  Спросит пароль — вставь его (при вводе символы не отображаются, это нормально) и нажми Enter.
- **Windows:** открой PowerShell (Пуск → набери «PowerShell») и введи ту же команду.

Если увидел приглашение вида `root@server:~#` — ты на сервере. Все следующие команды вводим там.

---

## Шаг 3. Установить Docker (одна команда)

Docker — это программа, которая запустит бота со всем необходимым внутри. Вставь в терминал:

```bash
curl -fsSL https://get.docker.com | sh
```

Подожди 1–2 минуты, пока установка закончится. Проверить, что всё получилось:

```bash
docker --version
```

Если в ответ напечаталась версия (например, `Docker version 27...`) — готово.

---

## Шаг 4. Скачать и настроить бота

Вставляй команды по одной:

```bash
git clone https://github.com/morgunovtech/devops-bot.git
```

```bash
cd devops-bot
```

```bash
cp .env.example .env
```

Теперь открой файл настроек в редакторе:

```bash
nano .env
```

Откроется текстовый файл. Стрелками спустись к строке:

```
TELEGRAM_BOT_TOKEN=your_token_here
```

Сотри `your_token_here` и вставь **токен из Шага 1** (вставка в терминале: правая кнопка мыши или Cmd+V / Ctrl+Shift+V). Должно получиться примерно так:

```
TELEGRAM_BOT_TOKEN=1234567890:AAEhBOweik6ad9r_QXMENQjcrGbqCr5yLYE
```

Больше ничего менять не нужно. Сохрани и выйди: нажми **Ctrl+O**, затем **Enter** (сохранить), затем **Ctrl+X** (выйти).

---

## Шаг 5. Запустить

```bash
docker compose up -d --build
```

Первый запуск собирает всё нужное — подожди 2–4 минуты. Когда команда закончится, проверь, что бот жив:

```bash
docker compose logs --tail=20
```

Если видишь строку `Bot started: @имя_твоего_бота` — всё работает.

---

## Шаг 6. Познакомиться с ботом

1. Открой Telegram, найди своего бота по username из Шага 1 (например, `@moy_devops_bot`).
2. Нажми **Start**.
3. Бот ответит: «🔑 Ты стал администратором» — с этого момента бот слушается только тебя.
4. Нажми кнопку **«➕ Добавить первый сайт»** и отправь адрес своего сайта, например:
   ```
   mysite.com
   ```
5. Бот сразу проверит сайт и ответит что-то вроде: «✅ mysite.com в мониторинге · Доступность: HTTP 200 (96ms) · SSL: 77 дн.»

**Всё, настройка закончена.** Дальше бот работает сам:
- проверяет сайты каждые 5 минут;
- молчит, пока всё хорошо;
- каждое утро в 9:00 присылает короткую сводку;
- если сайт упадёт — напишет сразу (и сначала перепроверит с других серверов, чтобы не тревожить зря).

Проверить, что уведомления доходят: **📱 Меню → 📋 Ещё → 🔔 Тест алерта**.

## Полезные мелочи (по желанию, в любой момент)

Всё ниже — опционально. Бот полноценно работает и без этого.

**Поменять время утренней сводки или включить «тихие часы»**
📱 Меню → 📋 Ещё → ⚙️ Настройки. Пара тапов, без правки файлов.

**Следить, что бэкапы реально выполняются**
Если на сервере есть задачи по расписанию (бэкапы и т.п.):
1. Добавь в `.env` строку с адресом сервера: `PUBLIC_BASE_URL=http://123.45.67.89:8080` (свой IP), затем `docker compose up -d`.
2. В боте: 📋 Ещё → 💓 Heartbeats → ➕ — бот выдаст готовую строку-«отметку», которую нужно дописать в конец команды бэкапа.
3. Теперь если бэкап молча перестанет выполняться — бот заметит и скажет.

**Узнавать, если умрёт сам бот**
Зарегистрируйся на [healthchecks.io](https://healthchecks.io) (бесплатно), создай «check», скопируй ссылку вида `https://hc-ping.com/длинный-код` и добавь в `.env`:
```
SELF_HEARTBEAT_URL=https://hc-ping.com/твой-код
```
Бот будет отмечаться там каждые 5 минут; пропадёт — healthchecks пришлёт тебе письмо.

**Продвинутое** — кнопка «Передеплой» для Cloudflare Pages, статус индексации Google/Яндекса, автоперезапуск контейнеров: все инструкции лежат прямо в файле [.env.example](../.env.example) рядом с нужными строчками.

---

## Если что-то пошло не так

1. **Первым делом** — в боте: 📱 Меню → 📋 Ещё → **🩺 Диагностика**. Бот сам проверит свои части и скажет, что не так.
2. Посмотреть логи на сервере:
   ```bash
   docker compose logs --tail=100
   ```
3. Перезапустить бота:
   ```bash
   docker compose restart
   ```
4. Бот не отвечает на /start — проверь, что токен в `.env` вставлен целиком и без пробелов (`nano .env`), потом `docker compose up -d --build`.

## Как обновлять бота

Когда выйдет новая версия:

```bash
cd devops-bot && git pull && docker compose up -d --build
```

Все твои сайты и настройки сохранятся — они живут в базе данных, а не в коде.
