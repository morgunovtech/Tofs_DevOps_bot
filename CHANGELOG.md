# Changelog

Что изменилось для того, кто держит бота. Бот обновляется сам (Dependabot → CI → автомерж → Railway и `:latest`), поэтому здесь только версии с номером; даты — даты мержа. Английские заметки к каждой версии — в [Releases](https://github.com/morgunovtech/Tofs_DevOps_bot/releases).

## 2.0.0 — 2026-11-23

Второй релиз: бот перестал быть «мониторингом с кнопками» и стал тем, что обещает README — молчит, пока всё хорошо, говорит по-человечески, чинит, что умеет, и обслуживает себя сам. Полный аудит (#45–#51) прошёл по четырём фазам: доступ и доставка, самоконтроль, внешние запросы и сторонние сервисы, тексты и экраны. Публичный контракт изменился (экраны, кнопки, переменные) — отсюда мажор.

**Главный экран и навигация** (#21, #31–#36, #42, #44, #51)
- Три кнопки под полем ввода — «🏠 Главная», «📖 Что я умею», «❓ Значки» — вместо меню ☰; «📖 Что я умею» рассказывает выгодой, а не свойством.
- Главная по блокам: сайты, соцсети, боты и системы; проблемы первыми, все сайты посчитаны; карточка сайта говорит всё, что бот о нём знает (снимок, скорость, ссылки, поиск), в один тап.
- Одни слова для «жив ли»: «на связи / молчит»; «Отмена» и «Назад» ведут к источнику; удаление — после вопроса; хвосты убранного функционала вычищены.
- Настройки — пять вопросов; копия базы и восстановление под капотом (#34).

**Тревоги и отчёты** (#8, #15, #17, #24, #26, #27, #51)
- Один словарь уровней: 🔴 — встать сейчас, 🟠 — не сегодня, ⚠️ — не смог проверить; только измеренное, без «мелочей» и жаргона; причины по-человечески, DNS без «изменились».
- Тишина не врёт: недоставленное повторяется с пометкой, свой простой не считается простоем сайта, пробная тревога из чата (#24).
- Помощники: тревоги 🔴 приходят ещё одному-трём людям (#27).
- Код-ревью закрыло пропущенный 🔴, застревающую очередь и ложные тревоги (#17); дайджест тихой очереди и исходная тревога после подъёма (#51).

**Что проверяется** (#1, #16, #18–#20, #29, #37–#41)
- Паритет с Uptime Kuma: проверка по ключевой фразе, настройки на сайт, окна обслуживания, публичная статус-страница, tcp- и ping-мониторы (#1).
- Битая ссылка — проблема, куда бы она ни вела; 5xx подтверждается временем; чистая ручная проверка сразу закрывает алерт (#18, #19, #29).
- API-адреса проверяются без шума SEO (#20); после обновления бот сразу перепроверяет поиск (#16); ложные h1 и sitemap исправлены (#15).
- Почта домена: принимает ли письма и не уходят ли они в спам (#37). Базовая безопасность сайта: `.git` и `.env` наружу, https, защитные заголовки (#38).
- Скорость у настоящих посетителей — по данным Google (CrUX), без своего замера на сайте (#39, #40). Честная проверка ИИ-ботов: для сайтов на Cloudflare бот не обещает «ИИ вас видят», а показывает, где проверить (#41).

**Самообслуживание** (#15, #23, #25, #43, #46, #47)
- Бот снова обновляется сам и сообщает об этом; база на постоянном диске проверяется при каждом старте; автообновление — только после тестов (#15, #25).
- Самоконтроль: догон пропущенных задач, проверка своей сети перед тем, как объявить сайт упавшим, границы значений (#46); сторож задач, check-host, контейнеры (#47).
- Боты и сторож — строкой с галкой в утреннем отчёте, как сайты (#23); статус другого бота на главном экране вместе с отметкой (#31); порядок в GitHub — в воскресном отчёте (#20).
- Готовый образ на ghcr.io публикуется сам после каждого зелёного `main`, `:latest` и `:sha-…`, amd64 и arm64 (#43); воспроизводимая сборка: lock с хешами, Actions по SHA, базовый образ по digest (#50).

**Безопасность и внешние запросы** (#45, #48, #49, #50)
- Фаза A аудита, 10 пунктов P0: кто владеет ботом, доставка тревог, порт 8080 только для прокси, docker.sock, восстановление базы, секреты в логах — `RedactingFormatter` (#45).
- Исходящие запросы пересчитаны и описаны в README («Что уходит с вашего сервера»): внутренние адреса никуда не уходят, у каждой строки есть выключатель; `/api/feedback`, ссылки, третьи стороны, виджет (#48).
- Флаппинг, статус-страница, почта, домен и DNS, сервисы, инциденты, аптайм — по одним правилам (#49); парсинг страниц в дочернем процессе, шторм тревог, тесты без сети, язык посетителей `STATUS_PAGE_LANG` (#50).

**Установка** (#28, #30, #41)
- Шаблон Railway: одна обязательная переменная — токен, том и домен уже в шаблоне (#28); предупреждение о тарифе Railway до того, как бот молча остановится (#41).
- Карточка задачи heartbeat: сначала вопрос, а не строка curl; задачу из `.env` можно убрать (#30). Прокси для Telegram (#41).

**Документация** (#51, этот релиз)
- README на двух языках: безопасность, что уходит с сервера, где хранить базу, экраны как в коде; `tests/test_docs.py` следит, что ссылки ведут куда-то, экраны названы как в боте, а `cp .env.example .env` ничего не меняет, кроме токена.
- Этот релиз: CHANGELOG, SECURITY, CONTRIBUTING, шаблоны issue и PR, `.mailmap`, CLAUDE.md и AGENTS.md; таблица «что проект создаёт снаружи» и раздел «Tests» в обоих README.

**Зависимости** — Python 3.14 → 3.15 в образе (#2, #14), библиотеки по субботам одним PR (#6–#13, #22, #52).

## 1.0.0 — 2026-07-29

Первый публичный релиз. Личный девопс в Telegram: мониторит сайты, чинит что может, проверяет видимость для поисковиков и ИИ-агентов — и молчит, пока всё в порядке.

- 📡 Uptime, SSL с контролем автопродления, домены, DNS, битые ссылки, 5xx по sitemap.
- 🔍 SEO/GEO: детектор noindex, пробы ИИ-ботами (GPTBot, ClaudeBot, PerplexityBot), контент без JS, Google Search Console и Яндекс.Вебмастер.
- 🔧 Самолечение для Cloudflare Pages: кнопки-действия, автопередеплой.
- 💓 Dead-man switch для бэкапов и кронов.
- 📱 Управление из чата: онбординг с одного токена, сайты, настройки, паузы.
- 📊 Тихая доставка, утренняя сводка, недельный отчёт с графиком, эскалация.

Установка: `docker compose up -d --build` и один токен от @BotFather. MIT. Назван в честь Тофса — ирландского терьера, который принимает аптайм близко к сердцу.
